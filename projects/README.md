## How to read these projects

Each page separates my contribution from the team's output, identifies the available evidence, and marks work that has not been independently reproduced.

The Datathon Final prize is a team achievement distinct from the Round 1 forecasting task. The 3MT project is an academic proposal and presentation. The Tableau case study documents workbook structure and metric definitions rather than providing a live public dashboard.

The recommender demo is executable on synthetic data; its metrics are not the original team benchmark. Original datasets, source notebook outputs, and the packaged Tableau workbook are not included in this portfolio.
